# 样课制作说明

- 用户希望围绕已有节点，生成短小的理解、回顾、应用课程；先试做一节，再考虑每日生成。
- 样课归档于文档目录，运行时独立于业务应用；首次制作时无既有 assets 或学习记录可复用。
- 核心内容来自真实节点，并以 Docker 官方文档补全应用解释。场景中的 A、B、C 是教学假设，不是用户实际运行的容器。
- 尚无作答或实际使用证据，因此不创建“已学会”的 learning-record。
- 所有练习在本地页面内完成；不发送答案、不访问账户接口、不使用持久存储，刷新后输入清空。
- 题目反馈是预先编写的解释，不是 AI 实时评阅。开放题请带回聊天讨论。
- 后续是否接入星图、生成频率与提醒方式，均未在本次样课中实现。
