# Mission: 把 Docker 星图概念用于实际判断

## Why
用户反馈，已有知识常常只看过概念，随后忘记，也很少使用。本次样课取材于其真实星图中的“镜像（Image）”和“容器（Container）”，用一个具体场景检验课程形式是否有帮助，而不是继续增加收藏。

## Success looks like
- 能解释从同一镜像创建的两个容器，为什么各自的文件修改通常不会相互同步。
- 能在明确没有共享挂载的场景下，判断删除并重新创建容器后，临时文件是否仍在。

## Constraints
- 约 5～8 分钟，仅一个核心区别；允许“不确定”，不设置倒计时和连续打卡。
- 独立本地 HTML 样课，不执行 Docker 命令，不修改星图，不自动生成后续课程。
- 只给选择题提供预设反馈；开放回答不自动评分、不声称已掌握。
- 本次课程与网页反馈不代表长期记忆效果。

## Out of scope
- Docker 安装、生产部署、存储驱动实现和数据卷实操。
- 每日调度、账户绑定、学习状态回写、自动评估和课程系统开发。
