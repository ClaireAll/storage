# Docker 样课 Resources

## Knowledge

- [Docker 官方：What is an image?](https://docs.docker.com/get-started/docker-concepts/the-basics/what-is-an-image/)
  用于解释镜像包含运行所需文件和配置、镜像创建后不直接修改。已在本次制作时读取。
- [Docker 官方：What is a container?](https://docs.docker.com/get-started/docker-concepts/the-basics/what-is-a-container/)
  用于解释容器是隔离运行的进程，而不是把镜像简单改名。已在本次制作时读取。
- [Docker 官方：Storage drivers，Container and layers](https://docs.docker.com/engine/storage/drivers/#container-and-layers)
  用于核对独立可写层、容器删除后该层移除、底层镜像不变，以及共享挂载的例外。该页对旧式存储驱动的实现说明不作为本节版本承诺。已在本次制作时读取。
- [Docker 官方：Persisting container data](https://docs.docker.com/get-started/docker-concepts/running-containers/persisting-container-data/)
  用于核对删除容器后自身文件改动不再保留，以及卷能独立保留、共享数据的边界。只用于概念解释，本节不执行其中的操作命令。
