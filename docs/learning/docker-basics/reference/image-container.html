镜像决定起点，
容器保留自己的改动。

亲爱的主人，这页供实际使用时快速查阅，不需要把所有术语背下来。

三个词，够用即可

  • 镜像 Image：创建容器时使用的文件和配置。已创建镜像的内容不直接改写，更新会形成新的镜像。官方依据
  • 容器 Container：以镜像为基础创建的隔离运行环境，不等于镜像本身。官方依据
  • 可写层：当前场景中容器自己的文件修改所在之处。删除该容器会移除这层，原镜像不随之改写。官方依据

遇到文件问题，先分清位置

文件原本就在镜像里？还是只在某个容器里新建或修改？另外，有没有共享挂载或程序同步？

本节只讨论没有共享挂载、没有同步、没有另存新镜像的情况。数据卷与绑定挂载需要另行判断。

也别把“停止后重新启动同一个容器”，混同于“删除后创建另一个容器”。
